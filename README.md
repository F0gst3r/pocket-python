# Pocket Python

Редактор Python в браузере: подсветка синтаксиса, автодополнение, выполнение
кода через [Pyodide](https://pyodide.org/) и модуль `turtle`, нарисованный на
canvas с зумом и панорамированием. Устанавливается как приложение на iOS,
iPadOS, Android и десктоп.

## Что умеет

- Запуск Python прямо на устройстве — без сервера, `print()`, `input()`,
  трассировки ошибок.
- `turtle` целиком в браузере: перо, заливки, окружности, текст, зум и
  перетаскивание холста.
- Открытие и сохранение `.py`-файлов.
- Проверка кода через Claude (по API OpenRouter) с автоматическим исправлением.
- Работа офлайн после первого запуска (service worker кэширует и Pyodide).

## Установка на iPhone / iPad

Откройте сайт в Safari → «Поделиться» → «На экран «Домой»».
Приложение запустится на весь экран, с адаптированной под тач раскладкой:
редактор во всю ширину, нижняя навигация и ряд клавиш с отступом и скобками,
которых нет на экранной клавиатуре iOS.

## Проверка кода через ИИ

Кнопка 🔑 в панели сохраняет ваш [API-ключ OpenRouter](https://openrouter.ai/keys)
(`sk-or-v1-…`) в `localStorage` — **только в вашем браузере**, он никуда не
передаётся, кроме `openrouter.ai`, и не попадает в этот репозиторий.

Запрос идёт на `https://openrouter.ai/api/v1/chat/completions`, модель —
`anthropic/claude-opus-5`. Сменить её можно одной строкой: константа `AI_MODEL`
в `index.html`; [список моделей](https://openrouter.ai/models) OpenRouter.

Ключ виден любому коду, выполняющемуся на странице. Это неизбежно для
приложения без серверной части — поэтому задайте ключу
[лимит расходов](https://openrouter.ai/settings/keys) и не вводите его на чужой
копии сайта.

## Локальный запуск

```bash
python3 -m http.server 8765
```

Затем откройте http://localhost:8765.

## Как устроено

Четыре файла, без сборки и зависимостей:

| Файл | Назначение |
|---|---|
| `index.html` | Приложение целиком: разметка, стили, редактор, `turtle`-шим для Pyodide |
| `sw.js` | Service worker: кэш оболочки и рантайма Python для офлайна |
| `manifest.json` | Манифест PWA |
| `apple-touch-icon.png` | Иконка для экрана «Домой» в iOS (непрозрачная, 180×180) |
